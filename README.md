Project-1-Biocomputing-Group-01

Overview
Group -01 project-1 involved retrieving gene and protein data from NCBI
and translating them into protein sequences
then to check the translation accuracy. 
this was also run once as group in one singular script. 

Workflow
1. Individual work  
Retrieved API accession numbers for assigned genes.  
Downloaded nucleotide FASTA, GenBank, and protein sequences.  
Stored all raw files in the data/ directory.  
Wrote Jupyter Notebook scripts for analysis and saved them in scripts/.

2. Group work
Reported sequence lengths and extracted headers.  
Performed protein translation and saved outputs in results/.  
Created a consolidated summary table as a group and stored it in results/.  
Pushed all files to GitHub both individually and collectively.

we have tried to do as much as we could  in jupyter notebook with automation
such that someone who has to clone the repo does not have to manually do anything. 

still, some commands were difficult at this point and had to be done manually.
